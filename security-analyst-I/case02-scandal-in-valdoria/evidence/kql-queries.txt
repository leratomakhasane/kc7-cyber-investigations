# Query 1 - Find the suspicious email to Sonia Gose
---
Email
| where recipient == "sonia_gose@valdoriantimes.news"
| where sender == "newspaper_jobs@gmail.com"
/* WHY: Found the initial phishing vector - job offer with malicious doc attachment */

---
# Query 2 - Check if Sonia clicked the link
---
OutboundNetworkEvents
| where src_ip == "10.10.0.3"
| where url has "promotionrecruit.com"
/* WHY: Confirmed click at 2024-01-05 10:23:17Z - execution phase began */

---
# Query 3 - Locate the downloaded malicious document
---
FileCreationEvents
| where hostname == "UL0M-MACHINE"
| where filename == "Valdorian_Times_Editorial_Offer_Letter.docx"
/* WHY: Established file arrival time + SHA256 hash - evidence of initial compromise */

---
# Query 4 - Detect PowerShell script execution
